# MinimalWeather

[English](#english) | [Español](#español)

<a name="english"></a>
## English

### Description
MinimalWeather is a lightweight desktop application designed to display weather information discreetly and efficiently on Windows systems.

### Goal
The main idea is to create an app that shows the current weather status via an icon in the notification area (System Tray), offering a quick reference without taking up screen space or consuming the resources required by default Windows widgets.

### Key Features
- **Notification Icon**: Shows the weather status (temperature/icon) directly in the taskbar.
- **Detailed Information**: Clicking the icon opens a window with more complete weather information.
- **Low Consumption**: Optimized to be very light and efficient, ideal for those seeking performance and minimalism.

### Requirements
- Windows
- .NET Framework / .NET Core (depending on project configuration)

### Installation and Usage
1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build and run.
4. The application will run in the background, accessible from the notification area.

## Español

### Descripción
MinimalWeather es una aplicación de escritorio ligera diseñada para mostrar información meteorológica de manera discreta y eficiente en sistemas Windows.

### Objetivo
La idea principal es crear una app que muestre el estado del tiempo actual mediante un icono en el área de notificaciones (System Tray), ofreciendo una referencia rápida sin ocupar espacio en pantalla ni consumir los recursos que requieren los widgets por defecto de Windows.

### Características Principales
- **Icono de Notificación**: Muestra el estado del tiempo (temperatura/icono) directamente en la barra de tareas.
- **Información Detallada**: Al hacer clic en el icono, se despliega una ventana con información más completa sobre el clima.
- **Bajo Consumo**: Optimizada para ser muy ligera y eficiente, ideal para quienes buscan rendimiento y minimalismo.

### Requisitos
- Windows
- .NET Framework / .NET Core (según la configuración del proyecto)

### Instalación y Uso
1. Clonar el repositorio.
2. Abrir la solución en Visual Studio.
3. Compilar y ejecutar.
4. La aplicación se ejecutará en segundo plano, accesible desde el área de notificaciones.
